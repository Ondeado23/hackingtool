HackingTool

A focused security-tool workspace for authorized testing, research, and defensive operations.

Install the original Python toolkit

Recommended one-liner

Installs prerequisites, clones the project, creates a virtual environment, and adds the launcher.

curl -sSL https://raw.githubusercontent.com/Z4nzu/hackingtool/master/install.sh | sudo bash

Manual installation

git clone https://github.com/Z4nzu/hackingtool.git cd hackingtool sudo python3 install.py

Then launch it with:

hackingtool

Requirements

  1. Python 3.10+ is required for the core toolkit.
  2. Go 1.21+ is needed by tools such as Nuclei, ffuf, Amass, httpx, and Katana.
  3. Ruby is needed by Haiti and Evil-WinRM.
  4. Docker is optional for Mythic and MobSF.
pip install -r requirements.txt
Use these tools only on systems you own or have explicit permission to test. The Python toolkit runs in a terminal on Linux, Kali, Parrot, or macOS—not inside this webpage.
